# 多语种游戏版本的缺陷外推与上架签发资料约定

以下记录全部为本地合成数据，业务名称、参与方及数量不对应真实企业。

日期使用公历，带Z的时间为UTC。缺失值使用JSON null，空列表表示已知集合为空。资料主键仅表示该来源记录身份，业务版本与原始对象字段另行保留。

缺陷严重度none、minor、major、critical依次升高。暴露按引用audience_weight加权，内容缺陷可影响相同指纹的引用，上下文缺陷仅适用于对应context。
random记录来自风险层内等概率抽取，概率见每条记录。complaint与recheck为定向来源，不能据此直接估整层缺陷率。
没有changes记录的内容在两个候选版本间字节相同。音轨变化还可能使invalid_contexts所列字幕时序证据失效，纯文本语言审校不因此自动失效。
审核员不得审核自己的译文。剧情组可以重叠，工时按实际接受的审核任务占用，已完成任务不退回工时。

## items

内容身份及原始作者。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 内容 |
| fingerprint | str | 字节内容指纹 |
| kind | str | 内容类型 |
| language | str | 语种 |
| author | str | 译作者 |

## references

剧情引用，上下文身份独立于素材身份。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 引用 |
| item | str | 内容 |
| scene | str | 场景 |
| branch | str | 分支 |
| context | str | 上下文指纹 |
| audience_weight | float | 预期暴露相对权重 |
| risk | str | 风险层 |

直接引用关系为item → items.id。

## versions

候选版及渠道内容集合。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 内容集合 |
| version | int | 版本号 |
| language | str | 语种 |
| channel | str | 渠道 |
| references | list | 引用集合 |
| issued_on | str | 候选生成日 |

## reviews

抽检、投诉及复查记录；定向记录没有概率样本资格。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 审核 |
| reference | str | 引用 |
| version | int | 审核版本 |
| reviewer | str | 审核员 |
| purpose | str | random概率抽检、complaint投诉、recheck定向复核 |
| inclusion_probability | float / null | 该设计的纳入概率 |
| defect_scope | str | 内容或上下文作用域 |
| severity | str | 严重度 |
| reviewed_on | str | 审核日 |

直接引用关系为reference → references.id。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 审核员 |
| languages | list | 合格语种 |
| kinds | list | 合格内容类型 |
| hours | float | 可接受工时 |
| available_on | str | 可用日 |

## groups

上下文必须共同审核或共同交付的引用组。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 剧情组 |
| references | list | 引用集合 |
| audit_hours | float | 整组审核工时 |
| must_deliver_together | bool | 是否不可拆交付 |

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 渠道 |
| max_major_exposure | float | 重大缺陷暴露上界 |
| confidence | float | 判断置信水平 |
| required_strata | list | 须有可外推证据的层 |
| block_severity | str | 禁止带出严重度 |

版本变化资料。

| 字段 | 类型 | 含义 |

| id | str | 变更 |
| item | str | 内容 |

| changed_on | str | 生效日 |
